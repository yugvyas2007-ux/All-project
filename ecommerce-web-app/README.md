# E-Commerce Web Application

A responsive e-commerce web application built with React JS and Tailwind CSS. It demonstrates an online shopping experience with simulated checkout, payment options, dynamic PDF invoice generation, and package tracking.

## Features
- Responsive layout for different screen sizes
- Simulated checkout with payment options
- Dynamic PDF invoice generation
- Package tracking

## Technologies Used
- React JS
- Tailwind CSS

## Project Purpose
This project showcases my front-end development skills through a responsive shopping interface and interactive e-commerce features.

## Note
The checkout process is simulated for demonstration purposes and does not process real payments.
